If you're getting a **"Virus detected"** message when trying to download a file, follow these steps:

1. Open **Windows Security**.
2. Click **Virus & threat protection**.
3. Scroll down to **Virus & threat protection settings** and click **Manage settings**.
4. Locate **Real-time protection**.

Turning off Real-time protection may allow the download, but it doesn't mean the file is safe. Only proceed after verifying the file is trustworthy, and keep Real-time protection enabled to protect your computer.
